# USER INSTRUCTIONS
A: Load Program
B: Assign 3 keys in "User Mode" with PRIN CONT & MOVES.
1. Key: "PRIN", to start a new game.
2. Input a number from 1 to 8 corresponding to the column you wish to
change. Ignore the decimal point: R/S.
3. (Optional) To see number of moves: Key MOVES.
4. (Optional if step 3 was executed) To continue: Key CONT.
5. Repeat step 2 until 1.1111111 is changes to 0.0000000.
6. To start a new game: go to step 1.
